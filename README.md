# Netflix Content Strategy & Library Analysis 🎬📊

## Project Overview
This project involves a deep-dive analysis of the Netflix content library (as of late 2019) using **Microsoft Excel**. The goal was to uncover patterns in Netflix's global expansion, content types, and audience targeting to provide data-driven "Strategic Decisions" for platform growth.

## Key Insights & Visualizations
* **Content Distribution:** Analyzed the split between Movies (67.5%) and TV Shows (32.5%), suggesting a transition toward serialized content for better retention.
* **Geographic Trends:** Identified the United States, India, and the United Kingdom as the primary content hubs, reflecting dominance in high-production entertainment markets.
* **Growth Trajectory:** Tracked the rapid content expansion phase starting in 2014, highlighting aggressive scaling of the library.
* **Audience Targeting:** Discovered a heavy concentration in mature-rated content (TV-MA), identifying a potential gap in family-oriented programming (TV-Y).
* **Duration Analysis:** Mapped movie runtimes, finding that Netflix optimizes for the standard 90–120 minute window to align with mainstream attention spans.

## Technical Features (Excel)
* **Data Cleaning:** Handled missing values (directors/cast) and standardized date formats.
* **Pivot Tables:** Used for complex data aggregation across genres, countries, and release years.
* **Advanced Charting:** Created a professional dashboard featuring Donut charts for distribution, Bar charts for regional ranking, and Area charts for growth trends.
* **Strategic Summarization:** Integrated "Insight vs. Decision" blocks to demonstrate the business value of data.

## Project Structure
* `netflix_titles_nov_2019.csv`: The raw dataset containing show IDs, titles, ratings, and descriptions.
* `Netflix_Dashboard.xlsx`: The final Excel workbook containing the cleaned data, pivot tables, and the visual dashboard.

## How to Use
1. Open the `.xlsx` file in Microsoft Excel.
2. Navigate to the **Dashboard** sheet to view the high-level summary.
3. Review the **Data** sheet to see the underlying cleaning and transformation steps.
